Discord Server Manager

A Flutter app for Android that manages Discord servers and sends media to Discord channels. The backend runs entirely on Cloudflare Pages Functions with D1 and Cron Triggers — no server to maintain.

Download the APK

Server manager

Moderation

Kick, ban, timeout, message purge, slow mode and the moderation log of a server.

Roles and access

Create roles, grant them and inspect the real permission bits of a member in a channel.

Channels

Create, rename, move and delete channels and categories.

AutoMod and verification

The keyword, spam and link filter of a channel and the verification level of a server.

Engagement

Welcome messages, announcements, reaction roles and the invite tracker.

Media sender

A queue with pause, resume and cancel, a background upload service and a history of every upload.

Setup

  • Create an application in the Discord developer portal and add a public client.
  • Register the redirect URI https://YOUR-PAGES-DOMAIN/auth/mobile-callback.
  • Select the scopes identify and guilds.
  • Copy env.example.json to env.json and build the app with flutter build apk --release --dart-define-from-file=env.json.

The full instructions are in the README of the repository.
